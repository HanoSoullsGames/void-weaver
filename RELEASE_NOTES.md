# Void Weaver 1.4.2

Космический 2D-рогалик-шутер: сектора, боссы, модули, скины и ежедневный забег.

## Скачать
- **Void-Weaver.exe** — портативная версия для Windows 10/11 (x64), установка не нужна.
- **void-weaver-pc.zip** — тот же exe + инструкция.
- **void-weaver-spider.zip** — браузерная сборка (открыть `index.html`).

## Играть в браузере
https://hano-games.netlify.app/games/void-weaver/

## Управление
WASD — движение, мышь — прицел, ЛКМ — огонь, Space — рывок, P — пауза, L — язык.

## Важно
При первом запуске рядом с exe появляется папка `Void Weaver Data` — сохранения. Не удаляйте её.
