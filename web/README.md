# VOID WEAVER — Космический 2Д экшен

Монолитный процедурный 2D-экшен на **чистом JavaScript + HTML5 Canvas 2D**.  
Никаких библиотек, спрайтов, шрифтов, аудиофайлов или сборки: корабль, туманности, боссы, паутина, частицы, **музыка**, HUD и **ангар прокачки** генерируются кодом.

Стартовое **меню** с настройками, **тёмным эмбиент-саундтреком**, **регулятором громкости**, **кастомным курсором**, **бесконечным режимом**, **Boss Rush**, **модулями оружия**, **магазином скинов**, **мобильным управлением** и переключением **RU / EN** входит в игру. Кампания запускается по кнопке «Начать кампанию»; из ангара, паузы и экрана итогов можно вернуться в меню.

В обновлении **1.1** появились комбо, graze-бонус, ранг забега, сохранение прогресса между сессиями и отдельное меню паузы.

В обновлении **1.2** — карта секторов с элитными и аномальными узлами, ежедневный забег, более сложные боссы и отдельная музыкальная тема для каждого босса. **Boss Rush открывается после прохождения кампании.**

В обновлении **1.3** усилен общий баланс: обычные враги стали крепче и агрессивнее, волны плотнее, а боссы получили больше HP и реальный урон. У Chronos Singularity появились гравитационный урон, волна времени и залп «осколков времени».

В обновлении **1.4** мобильное управление упрощено: один стик движения, постоянный авто-огонь и кнопка рывка. Добавлены две раскладки — стик слева/рывок справа и наоборот; переключатель доступен только на телефоне в настройках.

**Запуск:** открой [`index.html`](index.html) в современном браузере (Chrome / Edge / Firefox).  
Либо подними локальный сервер:

```powershell
cd void-weaver-spider
python -m http.server 8080
# http://127.0.0.1:8080
```

Звук и музыка включаются после первого клика по меню — этого требует политика автозапуска браузеров.

Быстрые ссылки: `?lang=en`, `?settings=1`, `?skins=1`, `?endless=1`, `?mobile=1`.

## Меню, музыка и язык

### Стартовое меню

При открытии игры показывается меню в стиле HUD:

- **«Начать кампанию»** — сбрасывает забег и запускает уровень 1.
- **«Продолжить»** — появляется, если есть сохранённый забег, и загружает последний чекпоинт.
- **«Бесконечный режим»** — бесконечные циклы секторов с растущей сложностью.
- **«Boss Rush»** — три босса подряд без волн и ангара; открывается после победы в кампании.
- **«Ежедневный забег»** — одна попытка в день с двумя модификаторами и локальным рекордом.
- **«Скины»** — магазин корпусов и выбор текущего скина.
- **«Настройки»** — язык, музыка, звук, громкость и подсказки управления.
- Язык переключается кнопками **RU / EN** или ссылкой внизу меню.
- Настройки сохраняются в `localStorage` и применяются при следующем запуске.
- `Enter` в меню также запускает кампанию.

В меню, ангаре и магазине скинов используется **кастомный курсор-прицел**.

### Возврат в меню и бесконечный режим

- В ангаре и на экране итогов сверху справа есть кнопки **«СКИНЫ»** и **«В МЕНЮ»**.
- На паузе открывается отдельное меню с продолжением, языком, громкостью и выходом в главное меню.
- «В меню» возвращает на стартовый экран без перезапуска текущего боя; кампания/бесконечный забег начнутся заново по кнопке.
- **Бесконечный режим** проходит кампанию циклами. После 8-го сектора цикл увеличивается, враги и боссы становятся сильнее, счёт и кредиты продолжают расти. Победы нет — только следующий цикл.
- После поражения в бесконечном режиме кнопка рестарта начинает новый бесконечный забег, а не кампанию.
- В HUD отображается `БЕСКОНЕЧНЫЙ РЕЖИМ · ЦИКЛ N`.

### Скины и курсор

Пять корпусов:

| Скин | Цена | Стиль |
|---|---:|---|
| СПЕКТР-07 | бесплатно | бирюзово-пурпурный |
| УГЛЕК | 400 | оранжево-золотой |
| ПУСТОТА | 650 | фиолетово-малиновый |
| ИНЕЙ | 900 | ледяной сине-белый |
| СОЛЯРИС | 1200 | золотой звёздный |

- Купленные скины и выбранный корпус сохраняются в `localStorage`.
- Покупка доступна за кредиты текущего забега — и в ангаре, и из стартового меню; после покупки скин остаётся навсегда.
- В стартовом меню кнопка покупки активна, если кредитов достаточно.
- Скин меняет корпус, свечение, двигатель, кабину, крылья, трассеры рывка и цвет вспышек выстрела.
- В меню, ангаре, магазине скинов, меню паузы и окне модулей курсор заменён на неоновый прицел; в бою остаётся штатный canvas-прицел.

### Громкость

В настройках есть слайдер **«Громкость» 0–100%**. Он управляет общим мастер-выходом (музыка + эффекты) и сохраняется в `localStorage`; `M` по-прежнему полностью выключает/включает звук.

### Музыка

Фоновая музыка синтезируется через Web Audio API в момент первого клика. Это **только тёмный эмбиент**: медленные пэды, низкий дрон, редкие колокольчики и шумовое дыхание. Никаких барабанов, весёлых лидов и synthwave-арпеджио.

- Трек не заканчивается: это бесшовный процедурный секвенсор, а не короткий зацикленный буфер.
- **Три похожих трека:**
  - **Void Drift** — Dm → Bb → F → C, 56 BPM;
  - **Cold Nebula** — C#m → A → E → B, 52 BPM;
  - **Event Horizon** — Fm → Db → Ab → Eb, 60 BPM.
- Треки чередуются по секторам; боссы получают свой вариант: Void Weaver — Void Drift, Nebula — Cold Nebula, Chronos — Event Horizon.
- Интенсивность меняет только громкость пэдов, баса и редких колокольчиков — без перкуссии.
- Внешних аудиофайлов нет; громкость выведена на отдельную шину.
- **Музыка: ВКЛ / ВЫКЛ** — в настройках.
- **Звук: ВКЛ / ВЫКЛ** (или `M`) — общий мастер-звук.
- Обе настройки запоминаются.

### Локализация

Интерфейс полностью переключается между русским и английским:

- меню и настройки;
- HUD, уровни, волны, цели, пауза;
- предупреждения боссов и FSM-подписи;
- ангар, карточки улучшений, сообщения о покупке;
- переходы между секторами и экран победы/поражения.

В игре язык переключается клавишей `L`; язык сохраняется в `localStorage`.

## Обновление 1.1

### Комбо, graze и ранг

- Убийства без урона собирают **комбо**; множитель счёта растёт до ×1.6.
- Комбо сбрасывается при попадании и через 3 секунды без убийств.
- Пролёт вплотную к вражеской сфере даёт **graze**: очки, вспышку и отдельный счётчик.
- В конце забега считается **ранг S / A / B / C** по точности, комбо и полученному урону.
- На экране итогов видны счёт, время, точность, ранг, максимальное комбо и graze.

### Сохранение и пауза

- Забег сохраняется в `localStorage` на **чекпоинтах**: старт сектора, ангар, покупка улучшения, установка модуля, пауза.
- В главном меню появляется **«Продолжить»**; после перезагрузки страницы можно вернуться к последнему чекпоинту с HP, кредитами, улучшениями, модулями и счётом.
- Поражение и победа очищают сохранение.
- `P` / `Esc` открывают отдельное **меню паузы**: продолжить, сменить язык, громкость, выйти в главное меню.
- Кнопка **«В МЕНЮ»** также есть в ангаре и на экране итогов.

### Модули оружия

После первого и второго босса открывается выбор одного из трёх случайных модулей. В забеге два слота:

| Модуль | Эффект |
|---|---|
| **Веер** | +2 болта под углом к каждому выстрелу |
| **Криоконтур** | −20% задержка огня |
| **Перегруз** | +30% урон |
| **Хоминг** | каждый 4-й болт самонаводится |

Модули складываются с улучшениями, отображаются в HUD, сохраняются в чекпоинте и действуют до конца забега. В Boss Rush модули не выдаются.

### Boss Rush

- Три босса подряд: **Void Weaver → Nebula Behemoth → Chronos Singularity**.
- Без волн и ангара; между боссами корпус ремонтируется на 30 HP.
- В HUD отображается `BOSS RUSH · 1 / 3`.
- В конце — экран Boss Rush Complete с рангом и статистикой.
- Рестарт с экрана итогов снова запускает Boss Rush.
- **Режим открывается только после победы в основной кампании**; до этого кнопка заблокирована.

### Карта секторов (1.2)

После ангара вместо автоматического перехода открывается карта следующего сектора с тремя узлами:

- **Стандартный** — обычные награды.
- **Элитный** — враги +35% HP, босс +40% HP, +120 кредитов и +300 счёта.
- **Аномалия** — один из трёх модификаторов:
  - **Метеоритный шторм** — дополнительные астероиды в каждой волне, +80 кредитов;
  - **Ионный шторм** — снаряды врагов быстрее на 22%, +120 кредитов;
  - **Золотая аномалия** — враги +15% HP, +180 кредитов.

Выбор действует только на следующий сектор. Карта не открывается в бесконечном режиме, Boss Rush и ежедневном забеге.

### Ежедневный забег (1.2)

- Одна попытка в день; после старта попытка считается использованной.
- Два модификатора выбираются детерминированно по дате:
  - **Стеклянный корпус** — 70 HP, счёт ×1.5;
  - **Охотник** — враги быстрее, кредиты ×1.5;
  - **Метеоритный шторм** — дополнительные астероиды;
  - **Перегруз** — +25% урон игрока, +20% HP врагов.
- Результат и ранг сохраняются локально; в меню показывается счёт и модификаторы сегодняшнего дня.
- Ежедневный забег не перезаписывает сохранение кампании и не открывает Boss Rush.

## Управление

| Ввод | Действие |
|---|---|
| `WASD` / `←↑→↓` | Движение |
| Мышь | Прицел |
| `ЛКМ` | Огонь (удерживать) |
| `Space` / `Shift` | Рывок с неуязвимостью |
| `P` / `Esc` | Пауза (меню паузы) |
| `M` | Звук вкл/выкл |
| `L` | Язык RU / EN |
| Слайдер в настройках | Громкость 0–100% |
| `R`, `Enter`, `Space` или клик на экране итогов | Перезапуск текущего режима |
| Мышь / палец в ангаре | Покупка улучшений, «Продолжить полет» |

На телефоне/планшете включается упрощённое управление:

- **один стик** — движение;
- **огонь постоянный**: стрельба идёт автоматически с автонаведением на ближайшую цель;
- **РЫВОК** — отдельная кнопка с противоположной стороны от стика;
- **II** — пауза с сохранением забега.

В настройках на телефоне есть переключатель раскладки:

- **«Стик слева»** — джойстик слева, рывок справа;
- **«Стик справа»** — джойстик справа, рывок слева.

Выбор сохраняется в `localStorage`. На ПК этот пункт настроек скрыт, а управление остаётся WASD/мышью.

Меню и настройки адаптируются под портрет и ландшафт; в горизонтальной ориентации кнопки меню раскладываются в две колонки.

## Кампания

Восемь секторов: пять боевых уровней с волнами обычных врагов и три босс-уровня.  
HP игрока и счёт переходят между уровнями. Перед следующим уровнем корпус ремонтируется на **30 HP** (в пределах максимума).

После зачистки каждого сектора открывается **ангар модернизации**: игра замирает, можно потратить кредиты на корабль и только затем нажать «Продолжить полет».

| # | Уровень | Тип | Содержимое |
|---|---|---|---|
| 1 | Дрейф в пустоте | Боевой | 3 волны, метеоритные дроны, первый разведчик, астероиды |
| 2 | Рой на горизонте | Боевой | 3 волны, больше дронов и скаутов, астероидные поля |
| 3 | Ткач пустоты | **Босс** | Void Weaver Spider: квазары, паутина, призыв миньонов |
| 4 | Плазменная завеса | Боевой | 3 усиленные волны, перекрёстный огонь скаутов |
| 5 | Поле искажений | Боевой | 3 волны, плотный рой и астероидные коридоры |
| 6 | Сверхновая Небула | **Босс** | Nebula Behemoth: звёздный шторм и протуберанцы |
| 7 | Последний рубеж | Боевой | Максимальная сложность: 38 целей, 3 волны |
| 8 | Пожиратель Времени | **Финальный босс** | Chronos Singularity: гравитация, инверсия, коллапс |

Боевой уровень завершается, когда уничтожены все враги всех волн.  
Босс-уровень завершается после смерти босса и проигрывания его death-анимации.

### Кредиты

- **+10 кредитов** за каждого уничтоженного обычного врага.
- **+200 кредитов** за победу над Боссом 1 — Void Weaver Spider (уровень 3).
- **+400 кредитов** за победу над Боссом 2 — Nebula Behemoth (уровень 6).
- Баланс отображается в верхнем HUD под счётом и в заголовке ангара.
- Кредиты и купленные улучшения сохраняются всю кампанию и сбрасываются только при новом запуске.

### Обычные враги

- **Meteor Drone** — маленький быстрый треугольный дрон. Летит к игроку по прямой с зигзагом, оставляет оранжевый искровой след; при смерти рассыпается снопом искр.
- **Plasma Scout** — неподвижный ромбовидный разведчик. Медленно покачивается на месте, заряжает и выпускает крупные медленные плазменные сферы; в фазе высоких уровней стреляет очередями.
- **Астероиды** — дрейфующие обломки. Блокируют траектории, наносят урон при столкновении и разбиваются от выстрелов.

## Ангар модернизации

Между уровнями открывается полупрозрачный экран **«АНГАР МОДЕРНИЗАЦИИ»** с текущим балансом кредитов и тремя карточками улучшений. Игра в этот момент заморожена.

Каждое улучшение имеет **5 уровней**. Цена следующего уровня удваивается:

| Переход | Ур. 0 → 1 | Ур. 1 → 2 | Ур. 2 → 3 | Ур. 3 → 4 | Ур. 4 → 5 |
|---|---:|---:|---:|---:|---:|
| Стоимость | 100 | 200 | 400 | 800 | 1600 кредитов |

| Улучшение | Эффект |
|---|---|
| **Плазменный двигатель** | +15% к базовой скорости корабля за каждый уровень. Улучшает и рывок, так как его скорость считается от скорости корабля. |
| **Энергетический щит** | +1 к максимальному HP за уровень; каждая покупка полностью восстанавливает HP. |
| **Сдвоенные пушки** | Ур. 1–2: −20% к базовой задержке выстрела за уровень (на ур. 2 суммарно −40%). Ур. 3+: два параллельных болта за выстрел. Ур. 4–5: дополнительно +15% урона за уровень. |

Кнопка покупки становится **серой и неактивной**, если кредитов не хватает или достигнут пятый уровень. Кнопка **«Продолжить полет»** закрывает ангар и запускает следующий уровень. После финального босса ангар не открывается — игра переходит на экран победы.

## Боссы

В 1.3 боссы стали заметно агрессивнее: больше HP, короче паузы между атаками, раньше вторая фаза, выше урон снарядов и контактный урон. Ориентиры: Void Weaver — 3600 HP, Nebula Behemoth — 5200 HP, Chronos Singularity — 8000 HP.

### Void Weaver Spider — «Ткач Пустоты» (уровень 3)

Классический паук с **8 независимыми глазами** и **8 лапами на процедурном IK**. FSM ровно из пяти состояний:

`IDLE → CHASE → ATTACK_QUASAR / ATTACK_WEB → IDLE → … → DEATH`

- **«Плевок Квазаром»** — заряженная сфера с аккреционными дугами, ярким ядром и составным шлейфом.
- **«Паутина Пустоты»** — веер неоновых лучей от пасти к краям арены с поперечной паутиной.
- **«Призыв Миньонов»** — растущие искажённые порталы, из которых выползают маленькие пауки. Это вторая ипостась `ATTACK_WEB` (`webKind = 'summon'`), поэтому набор из пяти состояний сохранён.
- На 50% HP — фаза II: больше лучей, плотнее паутина, агрессивнее квазары.

### Nebula Behemoth — «Сверхновая Небула» (уровень 6)

Огромное аморфное облако розово-ядовитой плазмы с вращающимся ярким ядром. Облако дышит, пульсирует и выбрасывает маленькие туманности.

`IDLE → ATTACK_STORM / ATTACK_PROTRUSION → IDLE → … → DEATH`

- **«Звёздный шторм»** — волны мелких плазменных капель, которые самонаводятся на корабль.
- **«Протуберанец»** — четыре длинных вращающихся луча из ядра, заставляющих игрока кружить между ними.
- На 50% HP — фаза II: больше капель, быстрее вращение, усиленные лучи.
- Смерть — вспышка сверхновой, ударные кольца и разлёт плазмы.

### Chronos Singularity — «Пожиратель Времени» (уровень 8)

Финальный и самый монументальный босс: чёрная дыра с массивным быстро вращающимся золотым аккреционным диском, фотонным кольцом и искажающими пространство кольцами.

`IDLE → ATTACK_WELL / ATTACK_DISTORTION → IDLE → … → DEATH`

- **«Гравитационный колодец»** — случайная воронка рядом с игроком физически притягивает корабль к центру; из неё нужно вовремя вырываться рывком.
- **«Искажение Хроноса»** — экран на мгновение инвертирует цвета, а от босса расходится кольцевая волна частиц. Снаряды игрока, пересекающие волну, замедляются и подсвечиваются золотым таймером.
- Смерть — **«Коллапс»**: диск и кольца сжимаются в точку, экран заливает полноэкранная белая вспышка, после чего открывается финальный экран победы.

## Прогрессия и интерфейс

- **Верхний HUD:**
  - слева — HP и готовность рывка игрока;
  - по центру — `УРОВЕНЬ X / 8`, название сектора, прогресс волн или полоса HP текущего босса, фаза и FSM-состояние;
  - справа — счёт, баланс кредитов, таймер кампании и статус звука.
- **Переходы:** плавная двухсекундная текстовка перед каждым уровнем (`// LEVEL 0X //`, имя сектора, задача), двухсекундная карточка `ВОЛНА X / Y` между волнами и ангар после зачистки сектора.
- **Экраны:** затемнение и зачистка сектора, ангар модернизации, отдельные экраны поражения и финальной победы со счётом, временем, точностью и достигнутым уровнем.
- **Счёт:** начисляется за врагов, астероиды, боссов и зачистку уровней; сбрасывается только при новой кампании.
- **Кредиты:** отдельная валюта для ангара; +10 за обычного врага, +200 за первого босса, +400 за второго.
- **Ремонт:** +30 HP перед каждым уровнем после первого (после покупок в ангаре).

## Технические особенности

- Один файл `index.html`, IIFE, без импортов и внешних ассетов. Вся графика процедурная; Aseprite не требуется.
- Боссы и опасности используют общий интерфейс (`update`, `draw`, `takeDamage`, `hitTest`, `getWarning`, `getDisplayState`, `updatePassive`), поэтому `Game` не зависит от конкретного босса.
- Процедурный двухзвенный IK лап, независимые глаза, FSM, Lerp/easing, альтернативные группы шагов.
- Прокачка хранится в `Game.upgrades`, применяется к базовым характеристикам `Player` через `applyUpgrades()` и переживает переходы между уровнями.
- Ангар — отдельный режим `Game.mode === 'shop'`: игровой цикл замирает, работает только UI, затем следующий уровень запускается кнопкой.
- Пул частиц с лимитом, кэшированные glow- и beam-спрайты, предрассчитанный фон, ограничение DPR и `deltaTime`.
- Тяжёлые полноэкранные `shadowBlur`-проходы заменены кэшированными спрайтами и короткими локальными свечениями — это заметно поднимает FPS без потери визуального объёма.
- Процедурный Web Audio: выстрелы, попадания, заряды, лучи, порталы, гравитация, инверсия, сверхновая, победа и поражение.

## Debug API

Открывается из консоли браузера через `window.VoidWeaver`:

```js
VoidWeaver.startLevel(6);              // сразу перейти на уровень 1–8
VoidWeaver.nextLevel();
VoidWeaver.clearLevel();                // завершить текущий уровень
VoidWeaver.forceAttack('storm');        // атака текущего босса
VoidWeaver.phaseTwo();                  // принудительная вторая фаза
VoidWeaver.killBoss();                  // запустить death-анимацию
VoidWeaver.killEnemies();               // уничтожить активных обычных врагов
VoidWeaver.spawnEnemy('scout', 2);      // 'drone' | 'scout'
VoidWeaver.spawnMinions(4);
VoidWeaver.addScore(1000);
VoidWeaver.addCredits(1000);
VoidWeaver.setCredits(500);
VoidWeaver.openShop();                 // открыть ангар из режима игры
VoidWeaver.buyUpgrade('engine');       // 'engine' | 'shield' | 'weapons'
VoidWeaver.setGod(true);
VoidWeaver.restart();
VoidWeaver.state;                       // { mode, level, phase, boss, playerHp, playerMaxHp, score, credits, upgrades, shop, ... }
```

Имена атак зависят от босса:

- Void: `'quasar'`, `'web'`, `'summon'`;
- Nebula: `'storm'`, `'protrusion'`;
- Chronos: `'well'`, `'distortion'`.

`F3` включает/выключает debug-оверлей (или открой игру с `?debug`). В debug-режиме:

- `1` / `2` / `3` — форсировать атаку;
- `4` — убить босса или всех активных врагов;
- `5` — вторая фаза;
- `9` — следующий уровень.
